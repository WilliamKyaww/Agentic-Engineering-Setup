# Development Workflow

## Start

1. Read repository state and the relevant requirement or checklist.
2. Inspect the working tree and affected implementation.
3. Confirm scope, acceptance criteria, risks, and verification.

## Implement

1. Work in one bounded vertical slice.
2. Keep tests and documentation aligned with observable behaviour.
3. Record new architectural constraints in `DECISIONS.md`.

## Verify and hand off

1. Run proportionate checks.
2. Review the diff and residual risk.
3. Update `STATE.md`, backlog/features, and `docs/journal/` when warranted.
4. Leave changes for human review unless a Git action is explicitly approved.
