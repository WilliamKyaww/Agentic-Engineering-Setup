# Checklists

Create dated, phase-specific checklists using
`YYYY-MM-DD-phase-name.md`. Each checklist should define status, dependencies,
entry conditions, implementation tasks, verification, exit criteria, and a
completion record.

Keep project-wide release or operational gates here as clearly named reusable
checklists. Link them from the roadmap and phase checklist instead of copying
their criteria into multiple documents.
