# Release Checklist

## Scope and evidence

- [ ] Release scope and known limitations are documented.
- [ ] Requirements and acceptance evidence agree with shipped behaviour.

## Quality

- [ ] Relevant automated checks pass from a clean environment.
- [ ] Required manual, accessibility, security, privacy, and device checks pass.

## Operations

- [ ] Configuration, secrets, monitoring, rollback, and ownership are ready.
- [ ] Data migration, retention, backup, and recovery are reviewed where relevant.

## Approval

- [ ] The exact release version has been reviewed in a safe environment.
- [ ] Human release and deployment approval is recorded.
